# Changelog

## Unreleased

- **The best model now, not a habit** (owner, field test F54 to F58, F60). `cstack route` ranks by measured quality first: image entries carry a dated leaderboard rank (`quality: {leaderboard, rank, as_of, source}`), and a rank counts while it is under 30 days old; tier, then price, break ties after it. The route always prints `best now`, the best-ranked model for the job, even when it cannot be called here, with what it needs (a provider, an adapter, a key, a price). A rank older than 30 days, or none for the top candidates, prints a warning naming the date and asks for a check of the live leaderboard before a paid batch; `cstack generate` says the same before an image run when the data is old. Only three ranks are recorded, as read on 2026-10-05: GPT Image 2.5 Sunburst #1, GPT Image 2 #3, FLUX.2 pro #41. fal serves GPT Image 2.5 Sunburst (`openai/gpt-image-2.5/sunburst/text-to-image`), so with `FAL_KEY` it is the reachable #1; the Flare variant and the edit endpoint are listed on fal with ids not yet verified, so they have no fal route. Routes can carry per-token prices (`per: token`), estimated only from a request's `token_estimate` and otherwise unpriced with the reason. fal's GPT Image 2 route is priced per quality at 1024x1024 (low 0.006, medium 0.053, high 0.211 USD); other sizes stay unpriced. The `openai-image` adapter is now real: the Images API, generations as JSON and edits as multipart, with the key sent only to `https://api.openai.com` and scrubbed from errors, calls that never left marked not charged, and routes for GPT Image 2 and both 2.5 variants, unpriced until a per-token price is verified. `notSent`/`neverSent` moved to `providers/errors.mjs`.
- **A reaction to the whole board is not a reaction to references** (field test F36). The make gate needs reactions to at least two individual references since the last pivot; a reaction to the reference packet or a folder no longer counts.
- **Keys from a .env without a shell** (own-brand run F47). `--env-from <file>` loads only the provider variables cstack declares, never prints a value, and reports malformed lines by number. The preamble says never to cat, grep or source a `.env`.
- **Calls that never left this machine cost nothing** (own-brand run F46). A fal request that fails on DNS, a refused connection, TLS or a malformed key header is booked as not charged, like a 4xx; a reset after sending stays booked.
- **The eval agent without your own context** (F41). `docs/evals.md` gives the `claude -p` flags that keep your personal CLAUDE.md, memory and MCP servers out of a run while still using your subscription.
- **React, then say yes** (field test F52). Reference reactions count from the last pivot (the latest `brief reopen`, or the previous approval of a brief edited without one), not from the latest approval, so a founder who reacts to references and then approves the brief keeps those reactions.
- **The eval runner survives a usage limit** (first live baseline, F49 to F51). `cstack evals run` stops the suite on a usage or rate limit, or when the agent fails twice running, and prints the fixture ids left to resume with; before, a limited run marked the rest ERROR in minutes. `summary.json` and `--record` rows are written after each fixture, so a stopped run keeps what it graded. A failed judge call says so instead of "no judge".
- **Fixture props (F40).** A live eval run failed on fixtures whose setups named files the case never had. New fixture field `setup_props` generates them when the case is built (GLB with the stated bytes, triangles, 4k textures and extras; drawn PNG; ffmpeg clips with freezes, drift or set loudness; stills; PDF; SVG and text; repo copies; flow plans; mockup renders), so nothing binary is committed. Every T2 fixture now declares where it starts (`workspace`, `setup_files`, `setup_props` or `fresh_workspace: true`), and `cstack validate` fails one that declares none. All 64 T2 cases build, and a test checks every prop. The GLB writer moved from tests to `scripts/lib/three/build.mjs`.
- **A founder can change their mind** (field test F37, F39, F38). `cstack brief approve <file> --by <founder>` records the yes with a fingerprint of the brief's content; `flows gate --stage make` refuses a brief edited since its approval. `cstack brief reopen <file> --reason "..."` takes an approved brief back after a pivot said in conversation, logs it under `amendments`, and make re-gates until the founder approves again. The founder brief gains `market` (price position, the founder's words on price, the "better X" anchor, trend horizon), `customer.cohorts` and `interview.conflicts` for rounds that contradict each other. Approval also marks where `state/feedback.jsonl` stood, so reference reactions from before a re-approval stop counting (F42), and keeps a copy of the approved version in `state/approved-briefs/`, so `reopen` says which sections changed since the yes (F45). `reopen` refuses a brief that was never approved (F43). `market` keeps `reach` apart from price and lists `inferred` fields for the founder to confirm (F44). `browse shot --out` prints the absolute, quoted path.
- **Field test F30 to F32.** `cstack tools` now tells detected from usable: a connected Cosmos MCP shows as NO, because Cosmos's terms allow only its own software or a browser and it publishes no MCP or API (the ones in circulation are unofficial). Research tools can carry `agent_use`; `providers` reports the usable route. `cstack browse shot --out <dir|file.png>` copies the shots there, and the browser lookup falls back to an installed Chrome or Chromium (macOS included). `brand init` creates `references/inspiration/`. An owner may accept that terms risk for one workspace (`research_tools.<id>.agent_use` with `accepted_by` and `date` in `cstack.config.yaml`); `tools` then shows the tool as allowed by the owner, and the default stays not allowed for everyone else.
- **Field test F28, F29.** The founder brief gains a `product` section (what is made, the founder's stances, functional add-ons, range and its limits, what it will never be), and the founding interview asks about it. `cstack prompt compile` now checks the recipe against the `prompt-recipe` schema, so a recipe that compiles also passes `brand check`.
- **Text in generated images stops the batch** (field test F20). `cstack image text` flags lettering, garbled text and logos with local OCR (tesseract) or a judge command, and exits 1 so a stop rule can run it after each image. With no engine it refuses rather than passing. The `mood-probes` probe gate runs it.
- **What fal billed** (field test F21). Ledger rows keep the provider's request ids. `cstack spend reconcile --provider fal` fetches fal's billing event for each request into `state/billing.jsonl` (new schema `billing-record`). `spend summary` shows billed against estimated, and whether the gap is within 25%.
- **A plan made before its flow gained `requires` still owes them** (F26), because the gate reads the library flow's `requires` too. The plan's source flow is its last `flow:` entry; the unchanged-copy check had been comparing against the first one. The founder brief gains the founder's ambition and how the brand talks to its customer (F27).
- **A brand from zero starts with the founder** (the owner's verdict on field test R3; F23, F24). `/brief` gains founding mode, which interviews the founder in rounds: why the brand exists, the customer, the brand as a person, assets and inspirations. It writes a `founder-brief` (new schema) that waits for the founder's yes. The `create-brand` workflow now runs founder interview, brief, customer and category, references the founder reacts to, territories, craft, and the brand's world. Flows can list `requires`. `mood-probes` requires an approved founder brief and a reference packet the founder reacted to, so `flows gate --stage make` refuses territory probes until both exist, or until the owner records a waiver, which travels with the work as a warning. Fixture `brand-from-zero-founder-first`.
- **Contact sheets and blind picks** (field test F22). `cstack sheet make` writes a contact sheet for stills, with `--png` to render it and `--blind` to show only shuffled codes, keeping the key in a sidecar. The sheet's pick mode shows random pairs and downloads picks.json; `cstack sheet import` turns the picks into pairwise `feedback-event` records on the source files. The `mood-probes` flow uses both, and the owner picks blind before seeing any review.
