# Changelog

## Unreleased

- **T2 fixture runner.** `cstack evals run` builds each case in its own workspace, hands the setup to any agent CLI (`--agent "claude -p ..."`), grades deterministic graders first and `llm` graders with a separate `--judge` command, and keeps every prompt, transcript, call log and verdict so `--recorded` can regrade a run without calling anything. Agent and judge calls go through the spend gate on the `--ws` ledger; `--record` writes `eval` records. Fixtures may name a `workspace` and `setup_files`.
- **Install everywhere, update in one step.** `cstack update` and the `/cstack-update` skill: fast-forward only (dirty files or local commits stop it with the list), `npm ci` only when the lockfile changed, every recorded host relinked, then what is new from this file. Skills check for an update once a session (`--snooze`, `--auto on`, `--checks off`). `./setup auto` adds GitHub Copilot CLI, Factory and Kiro when present; setup records what it installed in `~/.cstack/`.
- **cstack's own imagery, the owner's picks (round 5).** The README figures are regenerated in the poster register, Klein blue ground and white type throughout: the hero is "Taste, made repeatable" with the word set four times and one letter slipped once; a new `docs/images/step-outside.svg` sign under "First, step outside"; drift as texture (fine lines against one flat block); the nine layers back as a transit line with the branch from Memory to Canon; the skill map with soft squares where a job did not stop and sharp ones where it did. All five pass `cstack svg legibility` at 324 px.
- **cstack's own imagery, round 4.** The editorial register, from the owner's reference board carried as mechanisms (`identity/references/inspiration/ref-editorial-board.reference.yaml`): jumping letters in headline words, specification sheets, a signal flag, grain and blur for what is undecided against flat squares for what is, a line gradient, tossed type once, a digit specimen. Eight posters in `identity/work/posters/2026-10-03-r4/` from `make-editorial.py`; canon entry `032c`; lineage row.
- **cstack's own imagery, round 3.** The Klein blue square becomes cstack's symbol, in a poster set in the Swiss register (`identity/work/posters/2026-10-03/`, generated by `identity/work/figures/make-posters.py`: the full stop, scale, step outside, the field, the stack, picture and band, a social card). - **Lessons from founder interviews (Open Residency podcast), as rules.** creative-direction: "not obvious, but true" (write the first-to-mind version and move past it; keep ideas that decode into a real product fact) and story over iteration; brief: identities, emotions, actions, where the artifact will live, and the core, participant, fan rings; creative-review: a pairwise winner must win the right audience; campaign-sequence: scarcity as a planned drop; claims-proof: validity lines need dated proof. packaging-system: key cues above the shelf blocker, countable ingredients, what the product is not, the counter object, an organic-pull step; shelf-test draws the blocker. Fixtures `obvious-first-idea`, `wrong-audience-winner`, `key-info-below-blocker`, `validity-line-without-proof`.
- **Creative strategy, field lessons** (from founders and operators interviewed on the Open Residency podcast): bets carry a `lane` (iteration or story) and a lane owner, and a production plan whose every bet iterates fails `cstack creative check`; a `talent_role` taxonomy family, with credibility partners left out of every performance read; offer-first diagnosis, wrong-audience winners rejected, first-second and ad-to-landing congruence, the claim smoke test, concept-plus-three-truths creator briefs; a story-lane example bet; 2 fixtures.

Method before making, and the media expansion: 3D, mockups, vector and symbols, AI video, typography.

- **Gates on quality, not only compliance.** `cstack flows gate <plan> --stage make|decide|final`: imagery with no usable media provider or a zero budget stops instead of being redrawn as vector (unless the owner approved a substitute), a visual decision needs probe sheets for at least two territories, and final work needs gold references and a side-by-side with one. Fixtures `imagery-without-provider`, `compliant-not-good`. `cstack route` lists each candidate's endpoint ids per host (the id a request's `model` takes) and ranks flagship models first (registry `tier`; `--tier draft` for probes) and counts host routes as reachable; Seedream 5.0 pro has its fal endpoints, still unpriced (fal bills it per compute-second). A ledger row priced from a route (with its `basis`) passes `brand check` again. A request the provider refuses at submit (a 4xx such as an unknown endpoint) books nothing (`charged: false`), and an unknown endpoint names the ids the registry carries; `flows gate` asks for a provider only at `make`. `flows plan` copies the library flow's `deliverable` (every library flow carries one; `--deliverable`, `--key-visual` override), so a fresh plan can pass the make gate; a generative step needs a media provider only when its skill calls a model. References take `storage: link_only` for third-party mood images that are linked, never stored. New library flows `mood-probes` (territory probes before type and colour exist) and `brand-hero-photo` (photographic or sculptural hero with the brand's own type composited), from cstack's own hero run.
- **Field test fixes (R0).** setup takes `--host`, quotes the alias path, replaces skill links left by an older checkout and removes skills it no longer has; `generate --dry-run` and `taste --dry-run` run the budget gate; `flows search` lists the workflows that cover an outcome; `flows check` refuses a hand-copied library flow; `cstack tools` matches connectors named after a tool (Cosmos) and agrees with `providers` on Taste Labs; a call through a host (fal) is priced only from that host's route in `registry/models.json` (`routes`), never at the maker's list price, with fal routes for FLUX.2 pro, flex, max and klein priced per megapixel and rounded up; `spend plan` prices items from the same routes and names each unpriced item and why, and an unpriced booking is never shown as a price; printed paths are absolute and quoted (in `brand check` error lines too); the quickstart shows lineage and eval records.
- **Originals and readers.** Every cstack write refuses `assets/official/` (generation, video, SVG, mockup and paste outputs, lineage sidecars; `--force` included). `brand/context-map.yaml` and `cstack brand context --task <name>` give each task its sections and files. `cstack brand guide` writes a human-readable `brand/generated/guide.html` from the same brand files, with the agent-readable context embedded.
- **Figures you can read.** `cstack svg legibility` checks text size at each display width (a README renders figures at about 324 px on a phone) and text contrast against the ground painted under it, for live and outlined type. creative-review gains page mode for long-form pages (information architecture and editor lenses, measured evidence; fixture `long-page-no-map`).

- **Rights pass.** Canon names and "in the style of" phrases fail `cstack prompt compile` and are refused by the media runner before any spend (`scripts/lib/prompt-names.mjs`); the runner refuses third-party captures (`work/browse/`) as generation input unless the job names recorded rights (`capture_rights`); `cstack browse` honours robots.txt (`--ignore-robots` only with the site owner's permission) and downloads media at a human pace; site-capture, competitor-intel and flow-research keep social networks, ad libraries and marketplaces to human browsing or approved APIs; the preamble adds rights rules for every generation (likeness consent, third-party marks, AI labelling, provider policies and model licences, confidential data); claims-proof gains EU and FTC sources; brand-workspace template ignores captures; the example brand is renamed Tessel Kiln (Lumen Field is a stadium); the CLDR licence text ships in `licenses/`; `package.json` is private so it cannot be published over the unrelated `cstack` npm package; typography rules from Butterick and Bringhurst are paraphrased rather than echoed.

- **Method before making.** Flow schema; `cstack flows list|search|show|plan|check`; preamble section 0.5; `flow-research` skill; 14 researched flows (type system, logo system, icon set, mockup set, 3D web hero, 3D packshot, social turntable, AR view, product hero video, brand mood film, paid-social cut-downs, UGC-style ad, logo sting, voice-first explainer). `flows check` refuses a plan without two compared candidates, a gate on every step, `compare_to_target` on every made thing, a stop condition and a stated target.
- **Skills:** type-director, symbol-design, vector-master, mockup, three-d, video-direction, video-assembly (30 in all). identity-system, product-fidelity, model-router, generate-media, claims-proof, brand-verify, creative-review and workflow updated for the new media.
- **Workflows:** logo-system, product-3d, product-video (11 in all); landing-page gains a 3D hero step, packaging gains 3D renders and mockups, paid-social gains video variants.
- **Craft checkers:** `cstack type scale|qa|font`; `cstack svg lint|reduce|kit`; `cstack mockup render|verify|check`; `cstack 3d inspect|frames|blender-script`; `cstack video probe|normalize|cuts|sheet|assemble|reframe|captions|safezone|audio|qa|deliver` (needs ffmpeg on your machine; cstack never installs it). - **Validate:** library flows must pass `flows check`; fixture format is checked; every `cstack` command named in skills, docs, fixture graders and flow gates must exist. The flow schema rejects unknown keys.
- **Search:** whole-word, stemmed, idf-weighted skill search with a trigger-phrase bonus (`ad` no longer matches `brand`), with routing tests.
- **Typography:** the type-director primer traces 20 common rules to the reasons behind them and adds verified studio lessons (Vignelli, Gerstner, Pentagram partners, COLLINS, Spiekermann); `docs/research/typography.md` holds the evidence; `cstack type scale --fluid` warns when a step can fail 200% zoom.
