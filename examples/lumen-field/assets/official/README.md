# Official assets (fictional)

Lumen Field is an invented studio. Its "official assets" in this example are short text records
standing in for the files a real owner would supply (a spec sheet, a care card, a swing-tag print spec).
No images, logos or fonts are included. In a real workspace this folder is never overwritten or
edited in place; new versions are added beside the old ones.

| File | Stands in for |
|---|---|
| `owner-interview-2026-09-14.md` | notes from the founding interview (source kind `user_instruction`) |
| `glaze-palette-v2.md` | the studio's glaze and colour spec (source kind `official_asset`) |
| `swing-tag-print-spec.md` | the printer's spec for the paper swing tag (source kind `official_asset`) |
| `care-card.md` | the care card shipped in every box (source kind `official_asset`) |
